# Gangemesteren

Mobiltilpasset, offline-klar webapp for trening på 2- til 9-gangen.

## Start lokalt

Kjør en enkel webserver i denne mappen, for eksempel:

    python -m http.server 8000

Åpne deretter `http://localhost:8000` i nettleseren. På mobil kan appen legges til på hjem-skjermen fra nettlesermenyen.

## Innhold

- Velg én eller flere gangetabeller
- 5, 10 eller 20 oppgaver
- Tre vanskelighetsgrader
- Direkte regnestykker, manglende faktor, divisjon, tallrekker og tekstoppgaver
- Fremdrift lagres lokalt i nettleseren
- Fungerer offline etter første innlasting

Oppgavene er nygenererte og gjengir ikke sidene eller teksten fra PDF-heftene.
